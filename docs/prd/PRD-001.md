## 1. 产品概述

### 1.1 产品愿景

构建一个全球人际关系记忆平台，让每个人都能记录自己的人生记忆，通过记忆中关联的人自然形成人际关系网络。记忆越多，连接越多，关系越近。

### 1.2 核心价值

- **以记忆为中心**：不是"添加好友"，而是通过记录记忆自然沉淀人际关系
- **关系可视化**：用共同记忆的数量衡量关系亲密度，形成可视化的关系图谱
- **人生时间线**：以时间为主线，串联人生的每一个重要时刻

### 1.3 目标用户

- 希望记录人生经历的每一个人
- 希望了解自己人际关系网络的人
- 希望通过记忆连接与他人的关系的用户

## 2. 核心业务流程

```mermaid
flowchart TD
    Start([用户访问网站]) --> Login{是否已登录?}

    Login -->|否| Auth[手机号注册/登录]
    Auth --> Profile{完善姓名?}
    Profile -->|否| CompleteProfile[填写姓名]
    Profile -->|是| Timeline

    CompleteProfile --> Timeline[进入主界面 - 记忆时间线]

    Timeline --> Action{用户操作}

    Action -->|创建分类| AddCategory[添加记忆分类<br/>预置模板/自定义]
    AddCategory --> FillCategory[填写分类信息]
    FillCategory --> SaveCategory[保存分类]
    SaveCategory --> Timeline

    Action -->|添加记忆| AddMemory[在分类下添加记忆]
    AddMemory --> FillMemory[填写记忆信息<br/>标题/描述/时间]
    FillMemory --> LinkPeople[关联人物<br/>输入姓名+关系类型]
    LinkPeople --> SaveMemory[保存记忆]
    SaveMemory --> Timeline

    Action -->|查看人物| ClickPerson[点击某个人物]
    ClickPerson --> PersonProfile[显示人物详情]
    PersonProfile --> ShowMemories[显示所有相关记忆<br/>数量=关系强度]
    ShowMemories --> PersonOption{操作?}
    PersonOption -->|返回| Timeline
    PersonOption -->|查看TA的记忆网| ViewTheirNetwork[查看此人的记忆网络]

    Action -->|可视化展示| ViewGraph[切换到记忆图谱视图]
    ViewGraph --> Graph[基于记忆关联生成的关系网<br/>连线粗细=记忆数量]
    Graph --> Timeline
```

## 5. 非功能性需求

### 5.1 性能要求
- 页面首屏加载时间 < 2秒
- 记忆列表加载支持分页，每页20条
- 图谱渲染支持1000+节点流畅显示

### 5.2 安全要求
- 手机号验证码有效期为5分钟
- 同一IP 1小时内最多发送10次验证码
- 用户数据加密存储

### 5.3 兼容性要求
- 支持主流现代浏览器（Chrome、Safari、Edge、Firefox）
- 移动端响应式适配（iOS 12+、Android 8+）
